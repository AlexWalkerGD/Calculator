## 📖 About the Project

**Calculator** is a simple digital calculator built using **HTML**, **CSS**, and **JavaScript**.  
It allows users to perform basic arithmetic operations with a clean and modern user interface.

🔗 **Access the live project:** [Click here](https://alexwalkergd.github.io/Calculator/)

## 🚀 Features

- ➕ Perform basic operations: addition, subtraction, multiplication, and division
- 🧹 Clear button to reset the calculation
- 🖱️ Interactive and responsive buttons
- ⚡ Lightweight and fast performance

## ⚙️ How to Run Locally

1. Clone this repository:

    ```bash
    git clone https://github.com/alexwalkergd/Calculator.git
    ```

2. Access the project folder:

    ```bash
   cd Calculator
    ```

3. Open the `index.html` file directly in your browser  
   *(or use a VS Code extension like “Live Server” to run it locally)*
